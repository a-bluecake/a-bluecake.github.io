有序列表使用 1. 2. 3. ......
有序列表（把大象放进冰箱）：

  1. 打开冰箱
  2. 把大象塞进去
  3. 关上冰箱

无序列表使用 - 或者 *
无序列表：

  • 阿斯蒂芬
  • 寒风呼呼
  • 阿斯顿回复
  • 阿斯蒂

任务列表使用 - [ ] ，可以在[]里面填写x表示勾选
任务列表（明天要做的事）：

  • 吃饭
  • 睡觉
  • 打豆豆

代码块使用 ```加上语言类别

  return 0;
}

表格使用|列名1|列名2|列名3| ，填写表头后第二行填写对齐方式与分割标记
第二行 使用---表示分割标记,使用:表示对齐方式
表格：

脚注使用[^脚注名]
添加[^脚注名]:解释信息
脚注：
markdown1

链接的格式是 []里面填写链接的文本，url里面填访问地址
url后面加字符串表示鼠标悬浮链接上时显示的文本
使用关键字解释的方式可以实现引用链接，但是大多数平台不适用
