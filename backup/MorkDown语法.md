**MarkDown 是一种轻量级标记语言，用简单符号标记文本结构，将纯文本转换成富文本，**
**在互联网行业里有很高的使用率**

**MarkDown 的后缀名是.md**

MarkDown中有两种元素
块级元素（占据一行）、行内元素（占据一行的一部分）

下方整理了一些MarkDown标签元素
通过github的Issues进行渲染
不同编辑器的规则不同，可能不支持全部语法

## 块级元素

标题使用 # 分为六级标题
# 标题1
## 标题2
### 标题3
#### 标题4
##### 标题5
###### 标题6

引用使用 > 表示
>这是一段引用

有序列表使用 1. 2. 3. ......
有序列表（把大象放进冰箱）：
1. 打开冰箱
2. 把大象塞进去
3. 关上冰箱

无序列表使用 - 或者 *
无序列表：
- 阿斯蒂芬
- 寒风呼呼
* 阿斯顿回复
* 阿斯蒂

任务列表使用 - [ ]  ，可以在[]里面填写x表示勾选
任务列表（明天要做的事）：
- [ ] 吃饭
- [x] 睡觉
- [ ] 打豆豆

代码块使用 ```加上语言类别 
代码块：
``` c
int main(){
  return 0;
}
```

数学公式使用$$ $$
数学公式：
$$
\frac{\partial f}{\partial x} = 2\sqrt{a}x
y' = 3x^2
$$
没有成功渲染数学公式

表格使用|列名1|列名2|列名3|  ，填写表头后第二行填写对齐方式与分割标记
第二行 使用---表示分割标记,使用:表示对齐方式
表格：
|姓名|年龄|成绩|
|:---|---:|:---:|
|张三|19|99|
|李四|20|89|

脚注使用[^脚注名]
添加[^脚注名]:解释信息
脚注：
markdown[^标记语言]

横线使用 --- 且与上方文字保持分割一行
横线： 

 ---


##行内元素

链接的格式是[]加上(url)    []里面填写链接的文本，url里面填访问地址
url后面加字符串表示鼠标悬浮链接上时显示的文本
使用关键字解释的方式可以实现引用链接，但是大多数平台不适用
url里面也可以填写#标题1实现跳转
链接：
[百度](baidu.com"一个搜索引擎")
[百度][id]
[id]: baidu.com"一个搜索引擎"
请参考[标题1](#标题1)

可以直接写url链接，自动转变为链接
URL:
www.baidu.com
https://www.baidu.com

图片链接格式是 ![]加上(url)
图片链接：
![百度](https://www.baidu.com/favicon.ico)

斜体：使用一对星号
加粗：使用一对双星号
行内代码：使用一对反引号  （多行代码使用一对 三反引号）
*斜体* **加粗**
`printf()`
