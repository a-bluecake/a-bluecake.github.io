MarkDown 是一种轻量级标记语言
MarkDown 的后缀名是.md

元素分为块级元素（占据一行）、行内元素（占据一行的一部分）
块级元素 
行内元素1 行内元素2 行内元素3

exanple.md

标题使用 # 分为六级标题
# 标题1
## 标题2
### 标题3
#### 标题4
##### 标题5
###### 标题6

引用使用 > 表示
>这是一段引用

有序列表使用 1. 2. 3. ......
有序列表（把大象放进冰箱）：
1. 打开冰箱
2. 把大象塞进去
3. 关上冰箱

无序列表使用 - 或者 *
无序列表：
- 阿斯蒂芬
- 寒风呼呼
* 阿斯顿回复
* 阿斯蒂

任务列表使用 - [ ]  ，可以在[]里面填写x表示勾选
任务列表（明天要做的事）：
- [ ] 吃饭
- [x] 睡觉
- [ ] 打豆豆

代码块使用 ```加上语言类别 
代码块：
``` c
int main(){
  return 0;
}
```

数学公式使用$$ $$
数学公式：
$$
\frac{\partial f}{\partial x} = 2\sqrt{a}x
y' = 3x^2
$$
没有成功渲染数学公式

表格使用|列名1|列名2|列名3|  ，填写表头后第二行填写对齐方式与分割标记
第二行 使用---表示分割标记,使用:表示对齐方式
表格：
|姓名|年龄|成绩|
|:---|---:|:---:|
|张三|19|99|
|李四|20|89|

脚注使用[^脚注名]
添加[^脚注名]:解释信息
脚注：
markdown[^标记语言]

横线使用 --- 且与上方文字保持分割一行
横线： 

 ---


链接的格式是[](url) []里面填写链接的文本，url里面填访问地址
url后面加字符串表示鼠标悬浮链接上时显示的文本
使用关键字解释的方式可以实现引用链接，但是大多数平台不适用
链接：
[百度](baidu.com"一个搜索引擎")
[百度][id]
[id]: baidu.com"一个搜索引擎"


[^标记语言]:告诉解释器文本结构/样式
