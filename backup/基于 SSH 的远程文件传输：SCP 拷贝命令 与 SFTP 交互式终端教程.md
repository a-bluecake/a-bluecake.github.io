## SFTP（SSH File Transfer Protocol）是一种SSH 文件传输协议
### 底层是ssh远程连接
参考 _ssh 远程连接教程_ #2

确定已经安装部署好了OpenSSH

## 使用SSH的 SFTP 子系统完成文件传输

### 连接SFTP
**命令 ： sftp 用户名@主机IP**
-P 参数选择端口号
-i 参数使用密钥
默认继承ssh的config配置
配置了config后，命令使用自定义的host名 代替 用户名@主机IP ，且自动使用配置的-P -i 等参数

提示连接成功后，终端输入显示
sftp>
表示成功进入sftp连接
常用命令

cd 切换目标主机目录
lcd 切换本地主机目录

pwd 查看目标主机目录
lpwd 查看本地主机目录

从本地上传文件到目标主机
**put [参数] 本地文件 目标目录**
使用参数 -r 上传文件夹 

从目标主机下载文件到本地
**get [参数] 目标主机文件 本地目录**
使用参数 -r 下载文件夹 

默认使用当前pwd/lpwd读取的工作目录为起始目录

### sftp可能不支持命令行常用命令，只提供了一些简单命令完成基础功能
列举：

rm 删除文件命令
rmdir 删除空文件夹
删除命令不支持-r参数，删除文件夹需要先手动删除文件夹内部文件

rename 远程重命名文件 / 文件夹 
不支持rm命令重命名，使用rename替代，不需要-r参数

! 临时进入本地主机的命令行，exit后返回sftp连接
!命令 用本地命令行执行命令

## SCP命令
**SCP（Secure Copy，安全拷贝）**，是基于 **SSH 协议** 的文件传输工具，复用 SSH 的 22 端口，传输全程加密。

scp [参数] 本地文件  user@主机IP:远程路径

scp [参数] user@主机IP:远程文件 本地路径

-r 参数 拷贝文件夹
-P 参数选择端口号
-i 参数使用密钥
-C 开启自动本地压缩文件，远程解压，节省传输带宽

配置了config后，命令使用自定义的host名 代替 user@主机IP ，且自动使用配置的-P -i 等参数
:后面默认使用登录用户的家目录作为当前目录
